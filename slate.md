AI Configuration Review (Anthropic Claude, Open AI ChatGPT, or Microsoft CoPilot)
 
SERVICE DESCRIPTION - ACA will conduct a security assessment of one (1) “instance” or “tenant” of the chosen AI platform (limited to Anthropic Claude, Open AI ChatGPT, or Microsoft CoPilot[1]). The assessment includes an analysis of Client’s AI platform configuration and aims to identify configurations that could expose it to cybersecurity risks. The Configuration Review aims to assess the organization’s security posture with a focus on user access and data protection.
 
DELIVERY & OUTPUT – Following the Configuration Review, ACA will prepare a report detailing key findings, issues, and recommended correction actions (if any). The report will be delivered in a virtual 1-hour readout call with Client. Following the readout, Client may request updates to the report based on what was discussed. Report updates are limited to two iterations after the readout.
 
CLIENT RESPONSIBILITIES – Client agrees to complete and return the request for information (RFI), provide relevant login credentials to cloud environment(s) within thirty (30) days following the contract effective start date to allow appropriate time for ACA to conduct the assessment thoroughly. Where applicable, Client also agrees to facilitate communications between Aponix and their MSP in order for ACA to successfully conduct the assessment.
 
[1] If ACA expands the list of AI platforms eligible for the AI Configuration Review, Client will be able to select from the updated list of AI platforms available for review beyond what is defined above.
